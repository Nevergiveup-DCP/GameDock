## 1.1 更新了什么

一个导不出来的库，不算真的属于你。所以这一版加了两条命令行：

- `GameDock.exe --stats` 写出 `%APPDATA%\GameDock\stats_report.txt`：总时长、各平台分布、时长前十名
- `GameDock.exe --export-csv` 写出 `%APPDATA%\GameDock\library_export.csv`：整库导出成表格，UTF-8 带 BOM，Excel 打开中文不乱码

完整记录见 [CHANGELOG.md](CHANGELOG.md)。

## 为什么会有这个东西

我 Steam 库里有 200 多个游戏。但过去半年，我每周至少有一次坐在电脑前，
把库从头翻到尾，然后关掉电脑去刷手机。

不是没游戏玩，是**选不出来**。

所以我写了个程序，只解决这一件事。

## 功能

**聚合游戏库** —— 自动扫 Steam（包括装在别的盘上的所有库位置）、Epic、
以及你指定的任意文件夹，合并成一个列表。

**统一计时** —— 不管游戏来自哪个平台，都记录游玩时长、启动次数、最后游玩时间。
并且会**导入 Steam 已经记录的时长**（读 `localconfig.vdf`）——
你在 Steam 玩了 88 分钟的游戏，不会在这里显示成 6 秒。

**数据有保护** —— 每次改数据前自动备份（保留最近 30 份），可以手动存一份
**永久快照**（永不自动删除），还有绑定本机的 HMAC-SHA256 完整性校验：
数据被外部改动会在界面里直接报警。
游玩记录是自己攒出来的，丢了买不回来。

**今晚玩什么** —— 给每款游戏算一个分，然后给你一个短名单。

**时间预算** —— 点一下「我只有 30 分钟」，它会把那些「你一次通常要玩两小时」的候选直接排除。
判断依据是**你自己的会话记录**，不是网上的游戏时长数据库。

**它会学你** —— 每个候选旁边有「就它了 / 换一个」。你选的会被加权，你跳过的会被降权。
评分规则本身还是写死的、可以读的，但**它的输入会随你的选择变化**。

**进度备忘** —— 每款游戏可以写一句「我停在哪」，比如
「第三章，刚打完雪山 BOSS，潜行键是 Ctrl」。过一阵再点启动，它会先把这句话
给你看一眼，再问你要不要开。

**封面** —— 可以自己选图，也可以按 Steam 编号拉官方封面。

**控制台程序识别** —— 有些「游戏」其实是控制台程序，启动时会弹一个黑窗口。
游戏坞直接读 exe 的 PE 头判断子系统，认出来之后可以一键隐藏那个窗口。

### 评分规则是写死的，这是故意的

```
状态：在玩 +60 ／ 搁置 +25 ／ 未分类 +15
刚开个头（3 小时内）        +20
玩得很久（60 小时以上）      +10
闲置超过 30 天              +18
闲置 7~30 天                +10
24 小时内刚玩过             -25
最后叠一点随机扰动
```

取前三名。**这里刻意没有用 AI**：今天推 A 明天推 B 的推荐，你两次之后就不信它了。
确定性本身就是这个功能的价值。

## 和 Playnite 的区别（这个问题一定会被问）

[Playnite](https://playnite.link) 比这个项目做得多得多——库管理、主题、插件、
模拟器、元数据刮削。**如果你要一个完整的库管理器，直接用 Playnite。**

游戏坞是故意做得更窄的。它只补 Playnite 没有的两层：

| 层 | 做什么 |
| --- | --- |
| **决策层** | 回答「今晚玩哪个」，而不是「我有什么」 |
| **记忆层** | 进度备忘，让搁置很久的游戏还能回得去 |

## 已知的短板（不藏）

- **只支持 Windows**
- **界面目前是中文的**，多语言还没做
- 界面是用 GDI+ 手画的，没有用任何 UI 框架。所以它看起来不太一样，
  而且在某些缩放比例下不是像素级完美
- **还没有安装包**，下载压缩包解压即用，或者自己编译
- 如果 Steam 库在响应慢的可移动硬盘上，扫描可能要 20 秒以上
  （已经在后台线程跑，窗口不会卡，但确实慢）
- **还没接 Steam 成就接口**，所以「进度」目前只能是手写文字

## 命令行

游戏坞是图形程序，但下面这些不用开窗口就能跑——写脚本方便，也能用来确认扫描到底扫到了什么：

| 命令 | 写出什么 |
|---|---|
| `GameDock.exe --scan-folder "D:\Games"` | `scan_report.txt`，这个目录扫到了什么 |
| `GameDock.exe --list` | `list_report.txt`，每个游戏的平台、状态、时长 |
| `GameDock.exe --launch "空洞骑士"` | 按名字启动游戏（不开窗口） |
| `GameDock.exe --stats` | `stats_report.txt`，总时长、平台分布、前十名 |
| `GameDock.exe --export-csv` | `library_export.csv`，整库导出成表格 |

文件都写在 `%APPDATA%\GameDock`。

## 编译

需要 .NET Framework 4.x（Windows 自带）。
不需要 Visual Studio，不需要 NuGet，没有任何第三方依赖。

```
build.bat
```

生成 `GameDock.exe`。

## 数据在哪

全部在 `%APPDATA%\GameDock`，**不联网、不上传**。
唯一会联网的时刻，是你主动点「从 Steam 获取封面」下载图片的时候。
